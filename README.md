# Taller-POO
Taller de POO hecho por: Wildrey Alzate, Samuel Restrepo, Maria Jose Muñoz y Samuel Castillo
 
---
 
## Descripción
Simulación de un sistema de videojuego inspirado en League of Legends, desarrollado en Java aplicando los principios de Programación Orientada a Objetos. El sistema permite registrar jugadores, crear partidas con distintos modos de juego, gestionar estadísticas y calcular puntajes según el rendimiento de cada jugador.
